<task id="3.1" type="edit">
<title>Cập nhật .gitignore cho user config files</title>
<read_first>
- .gitignore
- autorun.json (xem format)
</read_first>
<files>.gitignore</files>
<action>
Thêm các patterns vào `.gitignore` để ignore user-specific config files chứa token nhạy cảm:

Thêm dưới block `obfuscate.sh`:
```
# User config files (contain sensitive tokens)
*.json
!package.json
!tsconfig.json
```

Giải thích: Ignore tất cả `.json` ở root, ngoại trừ `package.json` và `tsconfig.json`. Điều này covers:
- `autorun.json`
- `darkphoenix1992.json`
- `hongnhung5690.json`
- `leemeimei4944.json`
- `trantran1629.json`
- `freeze.voz5276.json`
- Bất kỳ file config user mới nào trong tương lai
</action>
<acceptance_criteria>
- `.gitignore` chứa pattern `*.json`
- `.gitignore` chứa pattern `!package.json`
- `.gitignore` chứa pattern `!tsconfig.json`
- `git status` không hiển thị `darkphoenix1992.json`, `hongnhung5690.json`, etc. là tracked/modified
</acceptance_criteria>
</task>

<task id="3.2" type="verify">
<title>Xác nhận cấu trúc root đã gọn gàng</title>
<read_first>
- .gitignore
</read_first>
<action>
Kiểm tra lại thư mục root sau khi cập nhật `.gitignore`. Các file ở root nên chỉ còn:
- `index.ts` — entry point
- `package.json` — npm manifest
- `tsconfig.json` — TypeScript config
- `run.bat` — launch script
- `README.md`, `CHANGELOG.md`, `LICENCE`, `SECURITY.md` — documentation
- `.gitignore` — git config

Các file `.json` config user vẫn tồn tại trên disk (cần để bot chạy) nhưng đã bị git ignore.
</action>
<acceptance_criteria>
- `git ls-files "*.json"` chỉ liệt kê `package.json` và `tsconfig.json`
- Không có file user config nào trong git tracked files
</acceptance_criteria>
</task>

</tasks>

</verification>

<success_criteria>
- `.gitignore` đã được cập nhật để ignore user config files
- Không có file nhạy cảm nào bị track bởi git

</success_criteria>
