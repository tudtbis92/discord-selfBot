# Milestone v1.0 Requirements

## Refactoring & Code Quality
- [ ] **REFACT-01**: Tái cấu trúc cấu trúc thư mục logic hơn (nhóm theo tính năng hoặc file type).
- [ ] **REFACT-02**: Rà soát, áp dụng rules linting/type checking và dọn dẹp các đoạn code rườm rà.
- [ ] **REFACT-03**: Loại bỏ các dependencies, script và file code rác không còn sử dụng.

## Bug Fixes & Optimizations
- [ ] **FIX-01**: Khắc phục các lỗi nhỏ (minor bugs) làm giảm trải nghiệm hoặc gây lỗi ngầm.
- [ ] **FIX-02**: Tối ưu hóa hiệu năng, refactor flow code để chạy mượt mà và an toàn hơn.

## Out of Scope
- Thêm tính năng/luồng chức năng hoàn toàn mới.
- Nâng cấp phiên bản major của frameworks nếu có rủi ro break code lớn mà không thực sự cần thiết.

## Traceability

- **REFACT-03** → Phase 1
- **REFACT-02** → Phase 2
- **FIX-01** → Phase 3
- **FIX-02** → Phase 3
