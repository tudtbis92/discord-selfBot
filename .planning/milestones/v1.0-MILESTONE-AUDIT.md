## 4. Cross-Phase Integration & E2E Flow Check

A rigorous review of E2E user flows and cross-phase wiring yields the following verified integration paths:

### 1. Bot Startup & Configuration Lifecycle
- **Flow:** `index.ts` -> `InquirerConfig(agent)` -> `agent.setConfig(config)` -> `agent.registerEvents()` -> `agent.checkAccount()` -> `agent.run()`.
- **Wiring:** Perfect. `BaseAgent` registers all event handlers synchronously *before* Discord login. captchas, RPC presences, and command registries initialize smoothly without concurrency locks.

### 2. Message Mentions & Conversation Interaction
- **Flow:** Message Received -> `mentionHandler(agent)` -> `ConversationManager` pulls history (Checks RAM -> Queries Redis if available on miss) -> passes history array to `GeminiService.chatAsDiscordBot` -> `GeminiService` queries API with `withRetryAndRotation` -> returns result -> writes asynchronously back to RAM + Redis -> replies to channel.
- **Wiring:** Flawless. Decoupled conversation handling isolates message state completely from the Gemini service. Key rotation prevents chat blockages. Non-blocking Redis setup avoids thread blocks if Redis is offline.

### 3. Graceful Shutdown & Cleanup Flow
- **Flow:** Terminal SIGINT/SIGTERM -> `mentionHandler.ts` hooks triggered -> resets autoChat active timers -> calls `ConversationManager.stopCleanupTask()` -> gracefully terminates ioredis socket connection.
- **Wiring:** Perfect. Hook listeners ensure zero hanging sockets or database connections when PM2 processes restart or shut down.
