# Milestone v1.1 Requirements Archive

**Status:** ✅ SHIPPED 2026-05-19  
**Total Requirements:** 7/7 Satisfied  

## Archive Specifications

### Config & Personality (AUTOCHAT-CFG)
- [x] **AUTOCHAT-01**: Extend bot config JSON schema with `autoChatCharacter` (personality prompt string), `autoChatBotIDs` (array of the other 4 participant bot user IDs), and `autoChatChannelID` (the shared auto-chat channel). Update TypeScript `Configuration` interface accordingly.
  - *Outcome:* **Validated.** Implemented in `src/typings/typings.ts` and interactive Inquirer prompts in `src/structures/Inquirer.ts`.
- [x] **AUTOCHAT-02**: Inject the configured `autoChatCharacter` personality into the Gemini system instruction so all generated responses align with the bot's assigned character role.
  - *Outcome:* **Validated.** Loaded dynamically during `onReady` in `src/structures/BaseAgent.ts` and set via `GeminiService.setSystemInstruction()`.

### Trigger & Interaction (AUTOCHAT-TRIG)
- [x] **AUTOCHAT-03**: Only trigger replies when the bot is explicitly @mentioned or replied-to in `autoChatChannelID`, AND the sender's ID is in `autoChatBotIDs`. Ignore all messages from unknown users.
  - *Outcome:* **Validated.** Enforced in `AutoChatManager.isTrigger()` and `enqueueTrigger()`, filtering unknown senders completely.
- [x] **AUTOCHAT-04**: Simulate human-like behavior: display typing indicator (`sendTyping`) + wait a randomized delay (5–15 seconds) before sending the reply.
  - *Outcome:* **Validated.** typing simulated in parallel with API call via `Promise.all` inside `AutoChatManager.simulateBurstTyping()`.

### Conversation Flow (AUTOCHAT-FLOW)
- [x] **AUTOCHAT-05**: Gemini decides in-character who to @mention next (0 or more bots from `autoChatBotIDs`). If no mention is decided → reply to the message that originally triggered the response.
  - *Outcome:* **Validated.** Parsed dynamic regex mentions matched against the list, routing using message replies (0 mentions) or standalone messages (1+ mentions). Long messages split conversionally.
- [x] **AUTOCHAT-06**: Manage shared per-channel conversation history via Redis/RAM dual-layer cache. All 5 bots read from the same channel history key to maintain full context.
  - *Outcome:* **Validated.** `ChannelHistoryManager` stores up to 20 entries in `autochat:history:{channelId}`, formatting prompts contextually. History written *before* sending.
- [x] **AUTOCHAT-07**: Implement conversation initiator mechanism: one configurable bot periodically sends an opening message + mentions the other bots to start a new topic/conversation.
  - *Outcome:* **Validated.** Atomically claimed via custom Redis Lua script `claimInitiator` tracking channel quiet time (15 mins) and round-robin index turn sequence.
