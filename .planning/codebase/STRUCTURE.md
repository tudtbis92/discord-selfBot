# Structure

**Date:** 2026-05-18

## Directory Layout
- `/`: Project root (contains `package.json`, `index.ts`, `tsconfig.json`, `run.bat`).
- `src/`: Source code directory.
  - `commands/`: Individual bot commands (e.g., `autochat.ts`, `ping.ts`, `joinv.ts`).
  - `config/`: Configuration definitions or instructions (e.g., `mentionInstruction.ts`).
  - `feats/`: Core background features/modules (`autoChat.ts`, `presence.ts`, `update.ts`).
  - `handler/`: Event handlers for different types of Discord events (`avatarHandler.ts`, `mentionHandler.ts`, `welcomeHandler.ts`).
  - `structures/`: Core classes and architectural building blocks (`BaseAgent.ts`, `ConversationManager.ts`, `gemini.ts`, `Inquirer.ts`).
  - `typings/`: TypeScript interfaces and types (`typings.ts`, `quotes.ts`).
  - `utils/`: Helper utilities (`logger.ts`, `messageUtils.ts`, `utils.ts`).
- `dest/`: Compiled JavaScript output (generated by `tsc`).
- `doc/`: Documentation files.
